This project now uses SQLite and the Django ORM — no manual SQL or database
server is required.

The schema (the Account and SecureFile tables) is created automatically by:

    python manage.py migrate

See README.md for full setup instructions.

--------------------------------------------------------------------------
Legacy note: earlier versions used MySQL with raw, string-concatenated SQL,
which was vulnerable to SQL injection. That has been replaced with the ORM.
See SECURITY.md, finding #4.
